# 노트 형식
문제 번호/이름 : (예시) 백준 11054 / 가장 긴 바이토닉 부분 수열
핵심 아이디어 : (예시) 맨 앞 인덱스에서 한번(dp_inc), 맨 뒤 인덱스에서 한번 가장 긴 증가하는 부분수열(dp_dec)을 구한다. 그리고 dp_inc[i] + dp_dec[i] - 1 = 해당 지점에서의 가장 긴 바이토닉 부분 수열 
실수/교훈(있으면) : (예시) dp[-1] 접근으로 쓰레기값에 접근, ans 미초기화해서 쓰레기값이 ans에 담김 -> 인덱스/초기화 습관화 필요.
시간/공간 복잡도 : (예시) O(N^2) / O(N)
게임 서버와의 연결 : (예시)LIS(성장 곡선)의 길이가 이론적으로 가능한 최대의 정상적 성장 곡선이므로,  
LIS의 길이보다 특정 유저의 성장 곡선(LIS)의 길이가 상당히 짧으면 치트로 의심해볼 수 있다.
